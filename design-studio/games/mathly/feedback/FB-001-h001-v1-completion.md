## Options and proposed resolution
These are deviations or interpretations for the designer to confirm or reject. I did not edit the packet.

1. **VIS-004 / VIS-005: desktop 1280×800 uses the portrait canvas.** Read literally, the landscape rule (width > height, usable width ≥ 568) would also apply to desktop, but SPEC also says "Desktop portrait canvas max width 440". So I use the two-column landscape only when the portrait canvas would give fewer than 3 rows (for example 844×390). Desktop stays portrait at 8×3.
2. **VIS-004: the section layout on short landscape screens (568×320).** Target and result sit in a left column, with the Expression / Cards / Controls tabs and the section on the right. With the plaques stacked above the tabs, the Expression section would be 120 px tall, below the 186 px that one row plus the status line and selection strip need. The selection strip would then sit off-screen, which the reviewer found. On portrait phones the plaques stay above the tabs as specified.
3. **VIS-001 / R-006: icon colour.** The packet SVGs use `currentColor`. CSS mask-image colouring fails under `file://` (a CORS error, which the studio QA counts as a console error), so icons render through `<img>` as the SVG's default black at 86 % opacity, which reads as near-ink. The files themselves are unchanged and use relative URLs. If exact ink matters, the fix is to inline the ten small SVG paths. That would duplicate the assets, so I'm asking first.
4. **VIS-002: the caret while a token is selected.** The caret is drawn right after the selected token, as in the atlas, and a card or operator inserted while a token is selected goes there. Done, a second tap, Escape and tapping empty space all put the player's previous caret back. Only Before and After move it.
5. **Header:** the 44 px header holds back, the `Mathly` wordmark (Georgia 25 px) with the board name in 12 px underneath (e.g. "Multiplication · 01"), and settings. The packet's header has only the wordmark. The board name is existing content.
6. **Typography:** the status line is 14 px (the atlas uses 12 px) for readability of "Cannot divide by zero" and similar messages. Result words ("Incomplete", "No value") are 23 px, and 20 px in the compact layout so "Incomplete" fits at 320 wide. Numbers keep 36 / 32 px.
7. **R-008: Home** now lists "Settings" as an outline button next to "How to play". Before, Settings was reachable only from inner screens. It is not a new feature.
8. Old Card Table art (`felt.webp`, `logo.svg`, `table-mark.svg`) is no longer referenced and was removed from `games/mathly-trails/assets/`. The published artifact still holds the old copies, unused.
