# Sweet play — design study

**Draft design, not a game implementation or approved handover.**

- `index.html`: interactive review with seven scenes, special-candy combinations and tool catalog. Run any local HTTP server from the repository root and open this file's URL.
- `DESIGN.md`: MC-010–019 proposed behavior, examples, acceptance checks, boundaries and rollout.
- `previews/`: seven captured design states. These are illustrative UI, not gameplay-test results.
- `VALIDATION.md`: actual browser checks and limits.
- `ASSETS.md`: existing art provenance and new CSS treatment.
- `overview.html`: static contact sheet of captured states.

The first-move and longer-chain scenes support tap, drag and keyboard selection. The stripe scene previews and demonstrates a row clear. Power-ups demonstrates the hammer confirmation. Sugar Rush demonstrates doubled points and remaining moves. Results links back to play and a speed-layout preview. Sticker book allows badge selection and explains locked achievements. Other tools/specials are proposals only. Preview state is disposable and never changes the live game's save.

The outer tabs, descriptive notes and Reset demo button are for design review, not proposed gameplay chrome. Exact game balancing, seeded refill, long-term saves and running speed records are not simulated.
