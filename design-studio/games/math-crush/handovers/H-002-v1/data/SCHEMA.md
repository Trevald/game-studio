# Data schema and evidence

levels.json schemaVersion=2, complete 12-level replacement data. IDs are existing 1-based stable IDs; positions are 0-based row-major indices. values length=rows×cols=25, integers1–9; witness is an orthogonally adjacent unique chain, sum=target. seed retains existing deterministic RNG. quota/moves govern completion. starThresholds=[twoStar,threeStar] in ascending order. contentVersion=sweet-v1 keys all new records. tools.hammer is initial charge count. rushEnabled and rushInitialCharge configure meter; initialSpecials lists unique cell/type entries (stripe/wrapped). freeInvalid implements introductory forgiveness.

baseline-witnesses.json contains full routes found using checks/baseline-engine.cjs, a frozen snapshot of the current pure engine using packet values and injected initial specials. Each route step indexes the board after the previous seeded refill. Scores exclude new combo boosts, tools, and Rush; no full H-002 engine exists yet. Replay/replace witnesses under the implemented engine before release. Search width24, up to4000 legal chains per node, no exhaustive-maximum claim. It is reproducible using `node checks/validate.cjs` from the packet. The script rewrites the evidence file deterministically; compare its hash afterwards.

mechanics-fixtures.json gives exact combo unions and point accounting before gravity. The common 4+6 chain sums10; blast-only values never enter the sum. Convert both selected values to 4+7 for the invalid-sum boundary: no removal, no combo points, no quota, ordinary level-specific error cost. Move fixture to an edge and clip geometry; no out-of-range cells. Rush fixtures cover activation, rounded-point doubling and expiry. Implement these through the actual new engine, not an independent test-only reimplementation.

achievements.json maps stable IDs, player-visible names/conditions and SVG paths. Conditions are labels; HANDOVER.md defines atomic eligibility/commit semantics. All assets paths are packet-relative.
