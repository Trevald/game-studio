# Layout and state contract
Use index.html for composition and assets, not executable gameplay or exact production control markup. Painted backgrounds are original game art; SVGs are editable runtime overlays. Labels/digits stay live. Cream#FFF3DD, plum#4A1736, raspberry#C81758, gold#FFD45A retained. Heavy borders and giant candy-shaped buttons are not required for rich art.

## Required state views
Idle: small ambient scenery, stable digits. Selecting: solid connected path+ordinals, current value, exact Release/Submit. Wrong: over-target text or Doesn't make target after release; free-level Try again, charged-level 1 move used. Blast preview: dashed halo on extra cells, separate jelly hits. Clearing: hold old target/expression until effect sequence done. Settling: falling candies land; new target slides into current slot after settling, then input enabled. On last target no next slot. Target change text “Now make12” once, never flashes. Pause/back/hidden cancels uncommitted path and stops loops. Reload opens stable committed state without replaying rewards.

Jelly goal: unambiguous patch texture and count; clearing patch briefly breaks into supplied shards, count decrements once. Invalid or cancelled action never cracks jelly. A remaining-jelly hint prefers a valid chain/blast hitting jelly; if none currently exists choose a board-changing legal chain, do not claim it clears jelly. Hint's guarantee is only legal move, not a shortest winning route.

Multiplication: persistent × and Multiply to make12, first cue3×4=12 on provided witness; no introductory modal. Restored attempt always restores operation label before accepting input. Scoring badge says Score×2, expression uses multiplication signs normally. Consider at least32px target digits and clear separation from bonus badge.

Win: objective completed, stars, current score/best, Chain/Blast/Moves bonus, Next/Play again; chapter completion reveal integrated behind results when leaving. Failure: remaining objective, Undo/Retry/Levels; no random decorative arithmetic implying a solution. Loading/error: reusable cream panel and Retry art; legible CSS fallback candies and actual void/jelly state remain usable. Save failure nonblocking. Asset errors are reported as visual defects, never silently considered final QA pass.
