# Asset use and delivery

ASSETS.json is the copy contract, including hashes and relative runtime destinations. Three1024×1536WebP world backgrounds (garden/chocolate/frosting) are the final painted scenery. The similarly named SVG scenes are reference-only early vector studies, not the production look. Load only visible/adjacent chapters and release unused decoded backgrounds. Soft cream separators between chapters hide non-seamless raster edges; do not pretend the three images tile seamlessly.

Existing match-bg.webp and match-atlas.webp supply gameplay scenery/candy texture. Atlas JSON corrected to match-atlas.webp; same sprite coordinates. Existing stripe/wrapped overlays included. New jelly,gap,board-shape previews,cloud,sparkle,pin,lock,star,operation icons,row sweep,burst,shards,glint and confetti are native SVG. tokens.css and motion.css provide editable style references. Numbers, level names, score and path stay live/native. No raster buttons, text crops, external fonts or sound files required. Synthetic sound design is specified in MOTION.md.

Copy only runtime assets, never index.html, model.py or reference-only SVG scenes. Do not inline raster as base64. Existing same-named assets are reused, not duplicated. Remove sticker assets from build publishing/loading as MC-020 requires (keep immutable historical packets). Total runtime footprint in this manifest: 1041592 bytes, including reused Match rasters. No new artwork generation is required to build this scope. Original generated PNGs remain in the creation library; optimized shipping WebPs are self-contained in the repo. Art is a prototype production source, not a claim of trademark clearance or final owner visual acceptance.
