# ADR-003 — variety, motion and a simpler progression system
29 October2026. State: owner-requested prototype scope; final balance/promotion pending. Supersedes H-002 sticker requirement and extends retained core-v1. Owner evidence/wording in STATUS.md, chat01a15e41-fe8f-7601-902e-c3250203b5a9.

Remove the confusing collection rather than explain/expand it. Make stars and world-map movement the rewards. Add spatial objectives so special placement matters, frequent authored targets and later target sequences. Preserve readable arithmetic and untimed play. Add product-only pilots after additive foundations; mixed operators remain out of scope. Deliver native SVG layers plus required raster art, no branded asset copies.

Alternatives: only reskin the map (doesn't improve decisions); replace all levels immediately (save/balance risk); add mixed operators immediately (learning overload). Chosen: phased content-versioned Journey preview, preserve Classic, promote only after playtest. H-003-v1 carries deterministic rules/data. Publication does not imply implementation verification or final owner acceptance.
