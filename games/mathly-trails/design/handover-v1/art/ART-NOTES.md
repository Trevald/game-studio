# Runtime art

felt.webp is a synthetic felt material generated for Mathly using the built-in image-generation tool on 19 October 2026, then encoded as 1024×1536 WebP at quality 72. No image-generation CLI was used. Original generation was already 1024×1536. Use the supplied WebP in the product; no source PNG download is needed.

Final prompt: “Use case: photorealistic-natural. Asset type: mobile puzzle game background texture. Generate a flat orthographic macro photograph of fine dark forest green poker-table felt, filling the entire portrait image edge to edge. Uniform fine short wool fibers, subtle organic material texture, low contrast, rich green approximately #12513D. Even diffuse lighting, no spotlight, no vignette, no seams, no objects, no cards, no markings, no typography, no border, no folds. Quiet premium tactile tabletop material that remains unobtrusive behind UI. Portrait 1024x1536.”

All SVG icons and the outlined logo are newly authored vector artwork. The CSS card, rim, drop shadows and panels are scalable runtime primitives. The system UI font and Georgia display fallback require no bundled font. The two recovered screenshots are supplied solely as project reference, not reusable runtime artwork. There are no stock photography dependencies.

The raster texture is the only non-vector material needed: its organic fibers are better represented by a compressed image. Increased contrast mode and image-load failure use a flat green fill. Keep all documentation and mockups outside the production bundle.

Revision 1.1 adds the authored vector table-mark.svg. Brass gradients, tiny decorative card pips, inset rail, calendar and patterned card back are CSS/vector shapes. The original generated felt is unchanged.
